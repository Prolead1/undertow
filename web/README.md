# Undertow web UI

React 18 + Vite + TypeScript (strict) frontend for the live policy cockpit. This directory is an
isolated Node toolchain: `uv run pytest` never needs Node, and `web/node_modules` / `web/dist` stay
out of git.

## Quick start

```bash
cd web
npm install
npm run dev          # http://127.0.0.1:5173 (proxies /api to 127.0.0.1:8050)
```

Start the backend in another terminal:

```bash
uv run undertow-ui serve            # or: uv run python -m undertow.ui
```

The Vite dev server proxies `/api` (including WebSocket upgrades) and `/openapi.json` to
`http://127.0.0.1:8050`. Set `VITE_API_BASE` to a full origin when the API is elsewhere; leave it
unset for the same-origin/proxy workflow.

## Scripts

| Script | Purpose |
|---|---|
| `npm run dev` | Vite dev server with HMR |
| `npm run build` | `tsc --noEmit && vite build` → `dist/` |
| `npm run preview` | Serve the production build |

| `npm run test` | Vitest (jsdom) one-shot |
| `npm run lint` | ESLint over `src/` |
| `npm run gen:api` | Regenerate `src/api/types.ts` from the committed `openapi.json` |
| `npm run gen:api:live` | Regenerate from a running server at `127.0.0.1:8050` |

## Generated API types

`src/api/types.ts` is generated by `openapi-typescript` and **must never be hand-edited**.
`web/openapi.json` is committed so the frontend can be regenerated without a live server:

```bash
# one-off dump (from the repository root)
.venv/bin/python -c "from undertow.ui.app import create_app; from undertow.ui.config import UiConfig; import json,sys; json.dump(create_app(UiConfig()).openapi(), sys.stdout)" > web/openapi.json

cd web
npm run gen:api
```

When the server is running, `npm run gen:api:live` fetches `/openapi.json` directly. Regenerate and
commit `openapi.json` + `types.ts` whenever U05's wire contract changes.

## Structure

```
src/
  App.tsx                 shell: left rail run selector + nav, top bar connection badge + pin tray
  router.tsx              CONTRACTS §8 routes, preserving ?run_id=&seed=&episode=
  theme/tokens.css        CONTRACTS §9 CSS-variable dark tokens
  api/client.ts           typed fetch wrapper (getRuns/getRun/getCurve/getTelemetry/...)
  api/useLiveStream.ts    one WebSocket, backoff reconnect, REST-tail fallback, live merge
  components/             Panel, Stat, Sparkline, Toolbar, EmptyState, RunBadge, Toast, PlotlyFigure
  views/                  U08–U10 placeholders (LiveCockpit, PolicyReplay, Leaderboard, Compare)
```

### Live merge

The hook owns one WebSocket to `/api/stream` (optionally `?run_id=`). Telemetry deltas are appended
to a buffer keyed by `(run_id, timestep)`; duplicates are ignored. A one-shot `GET /api/runs` on
mount populates the left rail even before the socket connects. On socket close/error the status
becomes `degraded`, the app falls back to polling `GET /api/runs` (rail refresh) and
`GET /api/runs/{id}/telemetry?since=` (telemetry tail), and reconnects with exponential backoff
(1 s, 2 s, 4 s … capped at 30 s). The fallback runs as a single poll chain: `startPolling` is a
no-op while a request is outstanding or already scheduled, an `AbortController` cancels the
in-flight request on reconnect/unmount, and a generation guard stops a late response from
rescheduling a dead chain. `PlotlyFigure` bumps Plotly's `revision` only when the figure `data`
changes, so live updates preserve zoom/selection state.

### Design tokens

All colors come from `src/theme/tokens.css` (`--bg-base`, `--accent`, `--bull`, …) and are mapped
into Tailwind via `tailwind.config.ts`. There is deliberately no light theme. Typography is Inter for
UI text and JetBrains Mono (tabular numerals) for numerics.

## Tests

`src/__tests__/smoke.test.tsx` covers the U07 contract: client URL/params + typed errors + the
`getCurve`/`getFigure`/`getRollout`/`compare` URL/body construction, live-merge dedupe + degraded
REST fallback + the single-in-flight poll-chain guard, query-param preserving navigation, empty
Plotly specs, and the presence of every §9 token. Charts are mocked in tests; no snapshots of Plotly
internals.
